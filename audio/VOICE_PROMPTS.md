## 一、声线档案（每角色一次，各句复用）

**【天殇】** 青年帝王 · 清冷虚 · 威严被疲惫压住
```
约二十岁青年男声，嗓音清冷略虚，带着强压的疲惫与空洞，威严却像在背诵别人写好的台词，语速慢、停顿多、尾音虚散不扬。
```

**【沈砚】** 中年文官 · 温润有礼 · 略湿似不实存
```
约四十岁男声，温润文雅有礼，嗓音偏柔，带一丝湿润与轻微回响感，像隔着水雾说话，语速从容，偶有停顿。
```

**【李司农】** 干瘦老臣 · 急切 · 气息不稳
```
约五十岁干瘦男声，语气急切焦虑，气息略虚不稳，语速偏快，句尾带颤。
```

**【阿檀】** 非人少女 · 清亮不甜 · 直白见血 · 尾音突收
```
约十四岁少女声，清亮但毫不甜腻，直白跳跃，语速偏快，尾音常突然收住，透着不属于人世的冷，情绪平淡却见血。
```

**【旁白】**（可选，本轮不配）
```
低沉疲惫的中年男声，语气冷静克制毫无感情，像史官诵读旧档，语速偏慢，句尾沉稳下沉，略沙哑。
```
